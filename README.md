# Ôn tập Luật Đấu thầu 2026

Ứng dụng HTML offline để học và luyện tập Luật Đấu thầu, được xây dựng từ tài liệu lý thuyết và ngân hàng câu hỏi ôn tập.

## Nội dung chính

- Lý thuyết được hệ thống theo từng chủ đề, có giải thích chi tiết và mẹo ghi nhớ.
- 390 câu hỏi thực hành theo từng phần.
- Sau khi chọn đáp án, app hiển thị đúng/sai và giải thích logic.
- Có bản HTML gộp một file để gửi sang điện thoại.
- Có bản HTML tĩnh dành cho iPhone/Chrome khi file local không chạy JavaScript.

## Cấu trúc file

- `index.html`: bản app chính dùng trên máy tính hoặc khi chạy qua web/GitHub Pages.
- `styles.css`: giao diện của app chính.
- `app.js`: xử lý tương tác câu hỏi, tiến độ, tìm kiếm chủ đề.
- `data.js`: dữ liệu lý thuyết, câu hỏi, đáp án và giải thích.
- `on-tap-luat-dau-thau-mobile.html`: bản gộp một file, có tương tác JavaScript.
- `on-tap-luat-dau-thau-iphone.html`: bản tĩnh dễ mở hơn trên iPhone/Chrome/Files.
- `ly-thuyet-on-tap-luat-dau-thau.md`: toàn bộ phần lý thuyết trích xuất dạng Markdown.

## Cách sử dụng

### Trên máy tính

Mở file `index.html` bằng trình duyệt.

### Trên GitHub Pages

Nếu repo được bật GitHub Pages, mở đường dẫn:

```text
https://vukimthanh8185-arch.github.io/On-tap-Luat-dau-thau-2026/
```

### Trên iPhone

Ưu tiên dùng file:

```text
on-tap-luat-dau-thau-iphone.html
```

Bản này đã render sẵn nội dung, phù hợp hơn khi mở file local bằng Chrome hoặc ứng dụng Files trên iPhone.

## Chủ đề ôn tập

1. Quy định chung, phạm vi áp dụng, khái niệm
2. Chủ thể, trách nhiệm, quản lý nhà nước
3. Kế hoạch, HSMT và quy trình lựa chọn nhà thầu
4. Tư cách hợp lệ, năng lực kinh nghiệm, bảo đảm cạnh tranh
5. Ưu đãi, đấu thầu quốc tế và hiệp định
6. Bảo đảm dự thầu, hợp đồng và xử lý hồ sơ
7. Mua sắm tập trung, y tế, trực tiếp, trực tuyến
8. Đấu thầu qua mạng và chào giá trực tuyến
9. Vi phạm, cấm thầu và kiến nghị
10. Tổng hợp tình huống lựa chọn nhà thầu

## Ghi chú

Tài liệu phục vụ mục đích ôn tập. Khi áp dụng vào công việc thực tế, cần đối chiếu văn bản pháp luật hiện hành và hướng dẫn của cơ quan có thẩm quyền.
